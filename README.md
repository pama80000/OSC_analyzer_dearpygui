# OSC Analyzer DearPyGui

## 概要
本プロジェクトは、DearPyGuiを利用したノードベースのオシロスコープデータ処理フローを提供するPythonアプリケーションです。GUI上で各種データ処理ノード（データ読み込み、時間指定切り出し、FFT、周波数フィルター、特徴量抽出、包絡線抽出、カスタムPython、波形表示）を自由に組み合わせ、全体のパイプラインを視覚的に構築・実行することができます。さらに、作成したパイプラインは保存および他のプログラムからの再利用が可能です。

## 特徴
- **ノードベース設計**: データの読み込みから処理、結果の可視化まで、各処理をノードとして独立して実装。
- **豊富なデータ処理機能**:
  - データ読み込み（TRCファイルまたはCSV）
  - 時間指定切り出し
  - FFT解析
  - 周波数フィルター
  - 特徴量抽出
  - 包絡線抽出
  - カスタムPythonコード実行
  - 波形表示
- **GUIベースのノードエディタ**: ノードの追加、接続、削除が直感的に操作可能。
- **パイプラインの保存とエクスポート**: 作成したパイプラインをJSON形式で保存、またはPythonモジュールとしてエクスポート可能。
- **テストコード完備**: 各機能のユニットテストにより、品質を担保しています。

## 必要環境
- Python 3.8以上
- DearPyGui（requirements.txtを参照）
- その他の依存パッケージ（requirements.txtに記載）

## インストール
1. リポジトリをクローンします：
   ```bash
   git clone https://github.com/pama80000/OSC_analyzer_dearpygui.git
   ```
2. プロジェクトディレクトリに移動し、依存パッケージをインストールします：
   ```bash
   cd OSC_analyzer_dearpygui
   pip install -r requirements.txt
   ```

## 使用方法
アプリケーションを起動するには、以下のコマンドを実行してください：
```bash
python -m src.main
```
これにより、ノードエディタGUIが表示され、各種ノードを利用してパイプラインを構築することができます。

## カスタムモジュールのエクスポートと再利用
作成したパイプラインは、GUI上の「モジュールとしてエクスポート」機能を用いて、外部から再利用可能なPythonモジュールとしてエクスポートできます。このモジュールには、現在のパイプライン処理が関数として定義され、他のプログラムから直接呼び出して同じ処理を実行可能です。

### エクスポート手順
1. ノードエディタのメニューバーから「実行」 > 「モジュールとしてエクスポート」を選択し、保存先とファイル名（例: `exported_module.py`）を指定します。
2. エクスポートされたモジュールには、各ノードの処理が関数として定義され、全体のパイプラインを処理する関数（例: `process_pipeline`）が含まれます。

### 再利用手順
エクスポートされたモジュールは、通常のPythonモジュールとして使用できます。以下に使用例を示します：
```python
from exported_module import process_pipeline

# 必要に応じて入力データやパラメータを設定し、パイプラインを実行
result = process_pipeline(file_path="path/to/data.trc")
```
※ エクスポートされたモジュールは、プロジェクトの依存関係に応じてDearPyGuiやその他の必要なモジュールをインポートしているため、実行環境にそれらのパッケージがインストールされている必要があります。

## 開発と拡張
- **ノードの追加**: 新たなデータ処理ノードを追加するには、`src/nodes/`ディレクトリにクラスを作成し、`Node`クラスを継承してください。その後、`src/main.py`の`register_node_types`関数で新しいノードを登録します。
- **デザインドキュメント**: 詳細な設計書は `docs/design.md` に記載されています。

## テスト
ユニットテストは `pytest` を使用しています。テストを実行するには、以下のコマンドを使用してください：
```bash
pytest
```
