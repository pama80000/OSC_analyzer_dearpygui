# オシロスコープデータ処理フロー設計書

## 要件定義書

### 目的
Dearpyguiライブラリを使用して、ノードベースのオシロスコープデータ処理フローを作成する。ユーザーがGUI上でノードを自由に組み合わせて、データ処理パイプラインを構築できるようにする。

### 機能要件
1. **ノードタイプ**
   - データ読み込みノード（Lecroy社のバイナリデータ.trcファイル、またはCSV）
   - 時間指定切り出しノード
   - FFT（高速フーリエ変換）ノード
   - 周波数フィルターノード
   - 波形から特徴量抽出ノード
   - 波形から包絡線をヒルベルト変換で変換するノード
   - その他、任意のPythonプログラムを入力しデータ変換できるノード
   - 波形表示ノード

2. **GUI機能**
   - ノードの追加・削除・接続
   - ノード間の接続によるデータフロー定義
   - 処理パイプラインの一括実行
   - 各ノードでの処理結果のグラフ表示。表示のオンオフは選択可

3. **パイプライン管理**
   - 作成したパイプラインの保存
   - 保存したパイプラインの読み込み
   - 外部プログラムからのパイプライン呼び出し

### 非機能要件
1. **パフォーマンス**
   - 大きなデータセットでも効率的に処理できること
   - リアルタイムでのグラフ更新

2. **使いやすさ**
   - 直感的なノード接続インターフェース
   - 各ノードの設定が簡単に行えること

3. **拡張性**
   - 新しいノードタイプの追加が容易であること
   - 外部からの呼び出しが簡単であること

## 設計書

### システム概略
システムは以下の主要コンポーネントで構成されます：

1. **ノードエディタ**：ユーザーがノードを配置し接続するGUIインターフェース
2. **ノードシステム**：各種処理ノードの基本クラスと具体的な実装
3. **データ処理エンジン**：ノード間のデータフロー制御と処理実行
4. **パイプライン管理**：パイプラインの保存・読み込み・外部呼び出し機能

### 機能設計

#### ノードエディタ
- Dearpyguiのノードエディタウィジェットを使用
- ドラッグ＆ドロップでノード追加
- ノード間の接続はマウス操作
- 各ノードにはパラメータ設定用のUIコントロールを配置
- 各ノードには処理結果表示用のグラフ領域を配置
- グラフ表示のオン/オフを切り替える機能

#### ノードシステム
- 基本ノードクラスを定義し、各種ノードはこれを継承
- 各ノードは入力ピン、出力ピン、パラメータ、処理ロジックを持つ
- ノード間のデータ受け渡しはNumPy配列を基本とする

#### データ処理エンジン
- トポロジカルソートによるノード実行順序の決定
- 各ノードの処理結果をキャッシュし、再計算を最小化
- 処理の進捗状況を表示

#### パイプライン管理
- パイプラインの構成（ノードの種類、接続、パラメータ）をJSON形式で保存
- 保存したパイプラインを読み込み、再構築
- 外部からPythonモジュールとして呼び出せるインターフェースを提供

### クラス構成

#### 基本クラス
1. **Node**：すべてのノードの基本クラス
   - 属性：id, 入力ピン, 出力ピン, パラメータ
   - メソッド：process(), update_ui(), serialize(), deserialize()

2. **NodeEditor**：ノードエディタのGUI管理
   - 属性：ノードリスト, 接続リスト
   - メソッド：add_node(), remove_node(), connect_nodes(), execute_pipeline()

3. **Pipeline**：パイプライン全体の管理
   - 属性：ノードリスト, 接続リスト
   - メソッド：save(), load(), execute(), export_as_module()

#### ノード実装クラス
1. **DataLoadNode**：データ読み込みノード
   - 機能：.trcファイルまたはCSVからデータを読み込む
   - パラメータ：ファイルパス, ファイル形式

2. **TimeSliceNode**：時間指定切り出しノード
   - 機能：指定した時間範囲のデータを切り出す
   - パラメータ：開始時間, 終了時間

3. **FFTNode**：FFTノード
   - 機能：時間領域データを周波数領域に変換
   - パラメータ：窓関数タイプ, 正規化方法

4. **FrequencyFilterNode**：周波数フィルターノード
   - 機能：特定の周波数帯域をフィルタリング
   - パラメータ：フィルタータイプ, カットオフ周波数, 次数

5. **FeatureExtractionNode**：特徴量抽出ノード
   - 機能：波形から特徴量（最大値, 最小値, RMS, ピーク数など）を抽出
   - パラメータ：抽出する特徴量の種類

6. **EnvelopeNode**：包絡線抽出ノード
   - 機能：ヒルベルト変換を用いて波形から包絡線を抽出
   - パラメータ：平滑化オプション

7. **CustomPythonNode**：カスタムPythonノード
   - 機能：ユーザーが入力したPythonコードでデータを変換
   - パラメータ：Pythonコード, 入力変数名, 出力変数名

8. **WaveformDisplayNode**：波形表示ノード
   - 機能：波形データをグラフとして表示
   - パラメータ：表示オプション（線の色, スタイル, マーカーなど）

### データフロー
1. ユーザーがGUI上でノードを配置し接続
2. 実行ボタンを押すと、パイプラインが実行される
3. データ読み込みノードからデータが読み込まれ、接続されたノードに順次渡される
4. 各ノードは受け取ったデータを処理し、結果を出力ピンから次のノードに渡す
5. 各ノードは処理結果をグラフとして表示
6. 最終ノードの出力が全体の処理結果となる

### 外部呼び出しインターフェース
```python
# 使用例
from osc_analyzer import load_pipeline

# パイプラインを読み込み
pipeline = load_pipeline("path/to/pipeline.json")

# パイプラインを実行
result = pipeline.execute(input_file="path/to/data.trc")

# または特定の関数として呼び出し
process_data = pipeline.as_function()
result = process_data(input_file="path/to/data.trc")
```
